# Сайт к первой годовщине

Готовый одностраничный сайт без сборщиков и зависимостей. Подходит для GitHub Pages.

## Как запустить локально

Просто откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. После публикации GitHub покажет адрес сайта.

## Что можно быстро поменять

- Тексты — прямо в `index.html`.
- Название фильма и тайм-код — в третьем экране `index.html`.
- Ссылку кнопки «Открыть сцену» — атрибут `href` у элемента с классом `scene-button`.
- Цвета — переменные в начале `styles.css`.

> Сейчас для третьего экрана указан фильм «Бойфренд из будущего» (About Time, 2013), тайм-код 01:48:00 и ссылка на поиск финальной сцены на YouTube. Если у вас есть точная ссылка на нужный фрагмент, лучше заменить `href` на неё.
